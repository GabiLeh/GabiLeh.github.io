# Meu portifólio
Ele está completo e é possível enviar mensagens.
## Linguagens utilizadas
* ``HTML``
* ``CSS``
* ``JavaScript``
## Como foram usadas
O ``HTML`` foi utilizado para criar o portifólio em si, a página de agradecimento e de erro, as duas últimas aparecendo após enviar uma mensagem na aba de "contato".
<br>
O ``CSS`` foi utilizado para estilizar o site, apenas o portifólio, o de agradecimento e de erro são HTML puros.
<br>
O ``JavaScript`` foi utilizado para redirecionar o usuário para as páginas de agradecimento e erro, pois não é possível fazê-las serem abertas direto pelo HTML, já que utilizei o FormSpree para que seja possível enviar uma mensagem pelo meu site. O FormSpree não permite que o HTML redirecione para outra página ao não ser a do próprio FormSpree.
