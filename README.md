# Meu portifólio
Ele está completo e é possível enviar mensagens.
## Recursos utilizados
* ``VS Code``
* ``HTML``
* ``CSS``
* ``I.A.``
## Como foram usadas
O ``HTML`` foi utilizado para criar o portifólio em si.
<br>
O ``CSS`` foi utilizado para estilizar o site, apenas o portifólio, o de agradecimento e de erro são HTML puros.
<br>
A ``I.A.`` foi utilizada para me auxiliar com o site, já que é um site complexo e estou no segundo semestre do SENAI. É claro que aprendi com ela e não deixei que ela fizesse absolutamente tudo.
